# Werewolf Pass-and-Play

Game Werewolf untuk dimainkan bersama menggunakan satu perangkat. Setiap pemain bergiliran melihat role dan melakukan aksi secara privat, sementara pemain lain menutup mata.

## Coba gamenya

Mainkan langsung di website: **[offline-werewolf.vercel.app](https://offline-werewolf.vercel.app/)**

## Alur permainan

1. Masukkan nama pemain dan atur role.
2. Bagikan role secara bergiliran dan rahasia.
3. Saat malam, pemain menjalankan aksi sesuai role. Werewolf memilih target; role khusus dapat menggunakan kemampuannya.
4. Saat fajar, hasil malam diumumkan. Pemain yang gugur dapat memicu kemampuan Hunter.
5. Pada siang hari, pemain berdiskusi dan memilih seseorang untuk dieliminasi.
6. Permainan berlanjut sampai semua Werewolf tersingkir atau jumlah Werewolf menyamai/melebihi pemain lain yang masih hidup.

Werewolf menang jika jumlah mereka menyamai atau melebihi pemain non-Werewolf yang masih hidup. Warga menang jika semua Werewolf tersingkir.
